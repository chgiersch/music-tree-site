# Mixtape: Music Tree, locked copy

The published copy of a private listening-history page. `index.html` is the
viewer; the `.enc` files are the data, encrypted in the browser's own
AES-GCM with a key derived from a passphrase. Nothing here opens without it.

Generated by the pipeline in the (local-only) music-tree repo; do not edit by
hand. Pages serves `main` from the root.
